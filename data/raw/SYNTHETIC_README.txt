SYNTHETIC TEST DATA - NOT OFFICIAL STATISTICS

Every synthetic_*.csv file in this folder was generated by twelveviews.data_gen (make synthetic) from a
single seed (2026), with an independent random stream for each dataset. The shapes follow broad, publicly
known patterns of inbound tourism to Thailand (a December-January high season, the collapse of arrivals in
2020-2021, revenue concentrated in a few destinations), and known structure is planted in them so that its
recovery by the twelve views can be measured. No value is an official statistic. Do not cite any number
derived from these files as a fact about Thai tourism.

The loader reads data/raw/<name>.csv when it exists and falls back to data/raw/synthetic_<name>.csv
otherwise, printing a warning. docs/data_sources.md lists the columns of each dataset and the kinds of
source that could replace it. synthetic_manifest.json records rows, columns and a description of each file.

The t-SNE coordinates (x, y) in synthetic_traveler_segments.csv depend on the platform and the
scikit-learn version, so `make synthetic` may reproduce them only approximately. Every other value, and
every number reported in the paper, is reproduced exactly.
